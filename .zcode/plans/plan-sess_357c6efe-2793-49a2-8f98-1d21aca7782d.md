## Part A — Backend: new `GET /users/me/stats` endpoint

**File: `needfull-backend/src/controllers/users.controller.ts`** — add `getMyStats`:
- `totalTasksPosted` — `SELECT COUNT(*) FROM tasks WHERE poster_id = $1`
- `totalTasksCompleted` — `SELECT COUNT(*) FROM tasks WHERE poster_id = $1 AND status = 'completed'`
- `averageRating` — `SELECT AVG(r.rating)::numeric(2,1) FROM reviews r JOIN tasks t ON t.id = r.task_id WHERE t.poster_id = $1`
- `totalSavedKobo` — `SELECT COALESCE(SUM(amount),0) FROM wallet_transactions WHERE user_id=$1 AND type = 'escrow_refund'`
- `totalEarnedKobo` — `SELECT COALESCE(SUM(amount),0) FROM wallet_transactions WHERE user_id=$1 AND type = 'escrow_release'`

Follows the existing controller pattern (try/catch, `db.query`, `res.json({ success: true, data })`).

**File: `needfull-backend/src/routes/users.routes.ts`** — add:
```ts
router.get("/me/stats", users.getMyStats);
```

## Part B — Frontend: rebuild poster dashboard in `feed/page.tsx`

Replace the poster return block (lines 769–832). Stats + categories added to the existing `Promise.all` in `fetchAll` (line 723); geo-dependent sections fetch separately.

### Sections

**1. Wallet Hero** — keep/enhance existing `WalletHeroCard` (balance, hide/show, escrow, Fund → `/wallet/fund`, Withdraw → `/wallet`)

**2. Quick Stats** — rebuild `StatCards` as 4 cards (Tasks Posted · Average Rating · Money Saved · Completed Tasks). Data from new `/users/me/stats`.

**3. Category Shortcuts** — replace hardcoded `POPULAR_CATEGORIES` with real `GET /categories` data. Icon chips linking to `/tasks?category=<id>`. Map `icon` string → lucide icon with fallback.

**4. Nearby Tasks** (new `NearbyTasks`) — fetch `/tasks?sortBy=nearest&status=open&perPage=6` **with lat/lng/radiusKm** so `distance` populates. Uses `navigator.geolocation` (same pattern as explore page, lines 215–233), graceful degradation if denied. Cards show **Budget / Distance / Urgency badge / Category chip**.

**5. Top NeedRunners** (new `TopRunners`) — fetch `/users/nearby-runners?lat&lng&radiusMeters=5000`. Horizontal scroll cards (reuse explore's `RunnerCard` pattern, lines 48–83): **Photo (Avatar) / Rating (trustScore) / Specialty (first skill) / Distance**. Tap → `/profile/<id>`.

## Notes / Trade-offs
- **"Money Earned" on a poster dashboard is conceptually odd** (posters spend, runners earn). I'll label it **"Money Saved"** (escrow refunds). The raw earned figure (escrow_release) will be available but the visible label fits posters better. Flagging for your review.
- Geo sections need location permission; degrade to empty state if denied.
- Average Rating shows "—" for new users until they receive reviews.
